# Y Soundboard

A lightweight Windows soundboard with per-sound roles, tuning controls, and virtual microphone support.

[![Download Y Soundboard](https://img.shields.io/badge/Download-Y%20Soundboard-701243?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/yLord24/Y-Soundboard/releases/latest/download/Y-Soundboard-Windows.zip)

## Installation

1. Download `Y-Soundboard-Windows.zip` using the button above.
2. Extract the entire ZIP file to a folder.
3. Open `YSoundboard.exe`.

Keep the `STAND SFX` folder beside the executable so the included sound library and configuration remain available.
